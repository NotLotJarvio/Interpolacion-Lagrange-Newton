# Práctica: Interpolación de Lagrange vs. Diferencias Divididas de Newton

Proyecto para la asignatura de **Métodos Numéricos (SCC-1017)** - Instituto Tecnológico Superior de Xalapa (ITSX).

## Descripción General
Implementación y comparación en Java de los métodos de interpolación polinomial por Diferencias Divididas de Newton y Polinomios de Lagrange.

## Requerimientos del Entorno
- Java JDK 17 o superior
- Visual Studio Code o Apache NetBeans

## Guía de Ejecución Rápida
Desde la terminal, ubicarse en el directorio raíz del paquete y ejecutar:
```bash
javac interpolacion/*.java
java interpolacion.PruebaInterpolacion
